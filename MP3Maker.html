Start the helper

MP3 Maker needs its small helper program running on this computer to make the audio. It is one file, MP3Maker.py.

First time: download it, then double-click it in File Explorer (it needs Python, with "Add Python to PATH" ticked). A black window opens and stays open while the helper runs. This page then wakes up by itself.

Next times: after that first run this button works: The browser may ask to allow opening MP3 Maker: say yes and tick "always allow".
